# Jobcrat

Jobcrat takes Rust code generated by C2Rust and replaces raw pointers that fit
Rust's disciplines with safe pointers. It has three components: ownership and
borrowing analysis, auxiliary analyses, and code generation. Ownership and
borrowing analysis is the core of Jobcrat and decides the kind of each pointer:
box, reference, or raw; auxiliary analyses provide information needed by other
components; code generation decides the exact type of each pointer by combining
the kind information from ownership and borrowing analysis with the mutability,
fatness, nullability, and offset sign information from auxiliary analyses and
applies type-directed transformations.

## Toolchain

The toolchain is pinned by `rust-toolchain.toml` (a nightly with the
`rustc-dev` component; rustup installs it on first use). Building also needs a
z3 library (the `z3-sys` crate links it; set `Z3_SYS_Z3_HEADER` and
`Z3_LIBRARY_PATH_OVERRIDE` if it is not on the default search path) and
libclang (used by bindgen).

## Build

```
cargo build --release
(cd deps_crate && cargo build)
```

`deps_crate` provides the crates that C2Rust-generated programs depend on; the
translator looks for its build products when it compiles an input program.

## Running

The binary is `jobcrat`; the wrapper script `jobcrat` at the top level runs the
release binary with the rustc sysroot on the library path and `deps_crate`
located. A translation is four passes, selected with `--pass`:

```
./jobcrat --pass expand,extern,preprocess,pointer -o OUT INPUT
```

`expand`, `extern` and `preprocess` bring the C2Rust output into the form the
analysis reads: macros expanded, extern declarations resolved to their
definitions, and duplicated asserts and unreachable code removed. `pointer` runs the ownership and
borrowing analysis, the auxiliary analyses, and code generation, and replaces
the program; `--bo-receipt FILE` writes the per-file digests of the emission.
Functions exposed to C are named with `--c-exposed-fn`.

## Benchmarks

`benchmarks/crown/` holds the twenty programs of CROWN's benchmark suite as its artifact ships them
(C2Rust output), `benchmarks/inator/` the eight programs of &inator's suite translated the same way;
`benchmarks/README.md` and `SHA256SUMS` describe them. `./jobcrat --pass
expand,extern,preprocess,pointer -o OUT benchmarks/crown/avl` translates one.

## Configuration of record

The analysis has no switches. For CROWN's twenty programs the evaluation set the
fallback slice extent to 2^28 (`JOBCRAT_FALLBACK_SLICE_EXTENT=268435456`);
`artifact/run.sh` sets it.

## Evaluation

`artifact/` reproduces the paper's evaluation (RQ1 to RQ3) in a container:
`docker build -f artifact/Dockerfile -t jobcrat-artifact .` from this
directory, then `artifact/README.md` for the runs, the hardware and the map
from each table to its results.
