# evaluation/ -- the counters the paper cites

Source only: the counters and drivers whose outputs are numbers the paper prints. Not built by the workspace; not in the
submission source zip. Scripts take their main inputs as arguments; other inputs are read at relative paths, named in the
table -- run from a directory where they resolve (links are enough): `scratch/main/<census>/` (a census's output, e.g.
`batch60sp/` with `emitted-trees/`), `crat/` (this repository, with the documentation repository checked out at
`crat/docs/`), `crown-artifact/` (CROWN's artifact), `worktrees/<solve>/` (a solve and its model cache), and the earlier
counter outputs the table names under `scratch/analysis-fanout/`. `pos_census.py` and `decl_walker_vs_census.py` import the
documentation repository's `agents/tools/seed_numbers.py` from the directory above their own (copy it to
`evaluation/seed_numbers.py`); `sloc104.py` reads it at `docs/agents/tools/seed_numbers.py`. Report numbers refer to the
analysis lane's reports.
